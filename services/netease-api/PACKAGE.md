# NeteaseCloudMusicApi 源码包

本目录包含 NeteaseCloudMusicApi 的源码，用于 RidgeRiceTalk 音乐机器人功能。

## 来源信息

- **仓库**: https://github.com/Binaryify/NeteaseCloudMusicApi.git
- **分支/提交**: PR-999 / d10089c5491a4a2f2ed870f0aeadf874117e0d2b
- **License**: MIT
- **纳入日期**: 2026-07-10

## 使用方式

服务端启动时会自动进入本目录执行 `npm install` 并启动 `node app.js`。

## 注意事项

- 请勿直接修改本目录源码。如需定制，应通过服务端包装层实现。
- `node_modules/` 已加入 `.gitignore`，不进入版本库。
- 更新版本时，应同步更新本文件中的来源信息。
